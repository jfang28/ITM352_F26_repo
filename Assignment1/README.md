# Data Structure Justification
A list of dictionaries was used to store the quiz questions. Such a structure was the best for this application as it allows me to easily create a for loop to ask each question and display each available option. It also allows me to easily retrieve and modify the correct answer for each question as well as hints for each question. 
The main goal of using this structure was to store the quiz questions with the options, correct answers, and hints in an organized and readable format for humans. Each dictionary in the list can be easily identified by the curly braces. Lists for answer options and hints can be easily identified by the square brackets. A standardized format is also used so each answer options, correct answer, and hints can be easily associated with a question.
# Function Design
The non-trivial custom function was designed in a way so the hints for each question would be printed sequentially as the user requested for more hints through indexing. Every time a hint was provided, +1 was added to the hint_index variable, which changed what hint was provided. This also prevents the same hint from being repeated. Once the hint_index was no longer less than the amount of hints in the "hints" list, the program would print "You have used all available hints.", preventing potential errors. The main purpose of this function was to lessen the amount of code on the main file, making it more readable by having the function on a separate file.
# Control Flow
Because I want the user to answer using the assigned letter to each option, if an input other than an assigned letter is inputted by the user, they will be nofitied that their answer was not valid and asked to answer again with a valid input. This will loop for the same question until a valid input is provided. The design quality goal of this control flow is to make sure that the program won't treat invalid inputs as a wrong answer and move on to the next question.
